# 뮤노폴리 (Mewnopoly)

재현이형이 가져온 로그라이크 보드게임 기획안의 1차 웹 데모.

## 어떤 게임?

- 0번 칸에서 시작해서 15번 칸에 도착하면 승리
- 매 턴 6면 주사위를 굴려 이동 (`-3, -2, -1, +1, +2, +3`)
- 앞으로 갈 때 지나간 칸이 **함정(구멍)** 으로 변할 수 있음
- 함정에 발을 디디면 0번 칸으로 즉시 리셋 (함정·코인·업그레이드는 그대로 유지)
- 굴린 결과에 따라 일정 확률로 **코인** 이 앞쪽 칸에 떨어짐
- 코인으로 업그레이드 상점에서 주사위·생존기를 영구 강화

## 어떻게 실행?

`demo/index.html` 을 Finder 에서 더블클릭하면 브라우저에서 바로 열림.
설치 같은 거 없음. 로컬 파일 단독 실행.
