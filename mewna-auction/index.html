경매 규칙

  • 플레이어 1명 + CPU 4명이 경매를 진행합니다.
  • 경매 1회 = 그림 A→B→C→D→E 5라운드 경매 + 판매 세션.
  • 5라운드 모두 자유경매 1등가로 진행합니다.
  • 감정가는 화면에 공개됩니다. 호가 판단 참고하세요.
  • 본인 재입찰 불가 — 누구든 연속으로 두 번 부르지 않습니다.
  • 10배속 보기 누르면 남은 시간이 ⏩ ×10 가속. 도중 다시 입찰하면 1배속 복귀.
  • 자유경매에서 마우스 휠 (위↑) / ↑↓ 방향키로 호가 단계 조절. Enter/Space로 입찰.
  • 자유경매는 CPU가 한 명씩 차례를 갖고, 내 차례에서 멈춰 입찰 또는 패스를 고릅니다.
  • 후반 1:1이 되면 3초 카운트다운이 돌고, 새 입찰이 들어오면 다시 3초로 돌아갑니다.
  • 모든 화면에서 아무 키 / 아무 클릭으로 다음 단계 진행.
  • 판매 세션 종료 시 재산 < 0 이면 게임 오버. 시작 자금 $3,000.
  • CPU 4명도 각자 시작 자금 보유. 잔고 부족하면 파산💸 — 입찰 안 함.
