- 줄 1240 (원본 기준): 게임 로직 주석 `전원 포기여도 즉시 종료 아님`

## 패치 3. 호가 = 그림 가격 10% 동적

**이유**: v7 룰에서 호가를 그림 가격의 10% 동적으로 정의. v6 기존 `minTick` 함수가 이미 10% 근사값이므로 함수 본체 변경 없이 주석만 추가.

**변경 위치**: `minTick` 함수 바로 위 (줄 ~420)

**변경 내용**: 주석 2줄 추가
```
// v8 패치 3: 호가는 그림 가격의 10% 근사. 5종 경매 자동 반영.
// (가격대별 수치가 이미 10% 근사값이므로 함수 본체 유지)
```

**검증**: `grep "v8 패치 3" v6-engine.js` 에서 1건 나와야 함.

## 패치 4. 예상가 비공개 → 공개

**이유**: v7 룰 R1 — 예상가를 화면에 공개해 플레이어가 호가 판단에 활용하도록 변경.

**변경 위치 (v6-engine.js)**:
- `renderAuctionFrame()` 함수 내 (줄 ~2637 직후): `bid-expected` 엘리먼트에 예상가 실시간 표시 코드 추가

**변경 위치 (v6-engine.html)**:
- 경매 화면 topbar에 `<span id="bid-expected" class="tb-value">$0</span>` 신규 라벨 추가
- 시작 화면 규칙 목록: "예상가는 절대 공개되지 않습니다" → "예상가는 화면에 공개됩니다. 호가 판단 참고하세요."
- 라운드 결과창: "예상가는 판매 세션에서 공개됩니다." → "예상가: $XXX (이미 공개됨)" span 추가

**추가 코드**:
```js
// renderAuctionFrame() 내부
const expectedEl = $('bid-expected');
if (expectedEl) expectedEl.textContent = formatMoney(state._hiddenExpected);
```

**검증**: `grep "bid-expected" v6-engine.js` 에서 1+ 건 나와야 함.

## 패치 5. 자동 대출 차단 가드 (v8 신규)

**이유**: v8 룰 — 자금이 시작가의 1.2배 미만이면 경매 입장 불가. 빈털터리 상태로 경매장 진입 방지.

**변경 위치 (v6-engine.js)**:
- `startCycle()` 함수 바로 위: `enterAuction(startPrice, showCenterModal)` 함수 신규 추가
- 파일 맨 끝 `window.__AUCTION_V6_DEBUG__` 아래: `window.MN9_AuctionEngine = { enterAuction, state }` 전역 노출

**변경 위치 (v8 game.js)**:
- `goToAuction()` 함수 신규 추가 — state.money < $3,600이면 toast 알림 + 차단
- `renderAuctionEngine()` 함수 신규 추가 — v6-engine.html fetch → inject → v6-engine.js 동적 로드
- `renderStudio()` 내 경매장 버튼 핸들러: `toast('Phase 3...')` → `goToAuction()` 연결

**변경 위치 (v8 index.html)**:
- `screen-auction-engine` 섹션 신규 추가
- `modules/auction-engine/v6-engine.css` link 태그 추가 (초기 disabled, 경매 진입 시 활성화)

**검증**: 
```js
// 브라우저 콘솔에서
window.MN9_AuctionEngine.enterAuction(3000, alert)
// → 자금 $0 상태면 alert 호출, true/false 반환 확인
```
