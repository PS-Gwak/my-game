## 🎮 한 라운드 흐름 (v2 — 자양동 2 명세 반영)

1. **라운드 N 시작** → 자동으로 **7장 드로우** (이제 드로우 버튼 없음)
2. **디스카드** — 손에서 카드 다중 선택 → 버리고 다시 드로우 (**한 라운드 3번 가능**)
3. **패 내기** — 슬롯 5칸 채워 족보 판정 → 분대 1개 만들어 대기 (**한 라운드 3번 가능 → 3분대 누적**)
4. **출전!** — 3패 다 내면 활성. 검투사 분대(3개 합쳐) 떨어짐
5. **핀볼 트랙 통과** — 지그재그 → 다이아몬드 → 톱니 → 핀 → 깔때기 → **최종 관문 (빠른 톱니 3개)** → 출구
6. **카메라가 1등 검투사 따라감** (가장 앞선 한 명 추적)
7. **결승선 도달한 검투사** → 점수 = Σ(품질 배수)
8. **상점** → 카드 팩 까기 → 3장 중 1장 골라서 덱 추가 (또는 다 패스)
9. **라운드 N+1** → 맵 기믹 살짝 임의 변형 + 1단계로
