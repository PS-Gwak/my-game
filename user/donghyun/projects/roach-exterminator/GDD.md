## 1. 컨셉 한 줄 + 개요

### 1.1 로그라인
> **"방 안의 가구를 밀어 바퀴벌레의 은신처를 부수고, 도망 동선을 직접 그려 포탑 사거리로 몰아넣는 박멸 퍼즐 로그라이크."**

### 1.2 게임 한 줄 정의
*얼음 슬라이딩 퍼즐 × 타워 디펜스 × 덱빌딩 로그라이크 × 클리커* — 한 방 안에서 *어디에 지을까* 가 아니라 *어디로 흘려보낼까* 를 푸는 두뇌 게임.

### 1.3 개요 (Vision)
| 항목 | 내용 |
|------|------|
| 장르 | 퍼즐 + 타워 디펜스 + 덱빌딩 로그라이크 + 클리커 |
| 시점 | 탑다운 2D, 타일 기반 |
| 기본 단위 | 1 라운드 = 1개 방 (스테이지) |
| 시간감 | 시뮬레이션 턴제, 슬로우/배속 토글 |
| 톤 | 스폰지밥 자가닥 카툰 ("안 귀여운 걸 귀엽게") |
| 시그니처 | 가구 슬라이딩으로 동선을 *그려* 박멸 |
| 가격대 | 5,000원 이하 / $5 이하 (인디 0~3달러 인지 묶음) |
| 승리 조건 | 라운드 내 모든 바퀴벌레 처치 |
| 패배 조건 | 가구 이동 횟수 / 자원 소진 (세부는 시스템 검증 후) |

## 2. 핵심 재미 (Core Fun)

### 2.1 퍼즐과 디펜스의 결합
타워를 *어디에 짓느냐* 의 게임이 아니다. **적이 어떻게 움직이느냐를 플레이어가 직접 디자인하는** 게임이다. 가구(얼음 슬라이딩)가 *경로 설계 도구* 이고, 포탑은 그 경로 위에 놓이는 *완성 도구*. 적의 움직임을 만든 사람이 그 적을 잡는다 — 두뇌 플레이의 자기완결성.

### 2.2 박멸의 쾌감
이리저리 도망 다니는 얄미운 바퀴벌레를 한곳에 몰아넣고 일망타진할 때의 시각적·심리적 카타르시스. 한 마리도 남기지 않는 *완전 섬멸* 이 핵심 보상 감정. **"한 군데에 몰아넣고 → 가구 앞 타워 진 → 슉슉 이동시키며 선멸"** 이 회의에서 도출된 시그니처 장면.

### 2.3 나만의 섬멸 덱 구축
매 라운드 무작위로 주어지는 강화 요소(포탑·강화·유틸리티)를 골라 시너지를 쌓는 덱빌딩의 묘미. Balatro 식 카드팩 구매 + 동일 타워·동일 티어 합성 레벨업 + 4슬롯 글로벌 유틸리티의 3중 빌드 축.

### 2.4 결단의 순간들 (대표 시나리오)

**시나리오 A — "한 번의 슬라이드, 세 마리 노출"**
> 방 가운데 가구 1개가 바퀴 3마리를 동시에 덮고 있다. 이 가구를 좌로 밀면 모두 노출 → 가장 가까운 가구가 우측 화생방 타워 앞 책장. 3마리 동시 도망 → 책장으로 몰림 → 화생방 1번에 전염 폭발. 단, 이 가구를 잃으면 다음 라운드 경로 설계가 어려워진다. *지금 한 번에 끝낼 것인가, 아껴서 다음 방까지 끌 것인가.*

**시나리오 B — "잔여 이동 보너스 vs 추가 한 수"**
> 이동 횟수 5/8 사용. 남은 3 중 1만 더 쓰면 마지막 1마리 처치 가능. 그러나 *한 수도 안 쓰고 클리어* 하면 잔여 보너스로 카드팩 1개가 더 열린다. 1마리를 클릭 스킬(파리채)로 직접 잡을 것인가, 가구를 한 번 더 밀어 안전하게 갈 것인가.

**시나리오 C — "합성 직전 타워 합성"**
> 핸드에 화생방 타워(1티어) 2장. 합치면 2티어 = 전염 범위 +1, 지속 +1턴. 다만 코스트가 부족해 다음 라운드 포탑 1개를 못 산다. *깊이를 살 것인가, 폭을 살 것인가.*

### 2.5 4층 플레이 순환

| 층위 | 주기 | 결정 단위 |
|------|------|-----------|
| **마이크로** | 가구 1회 이동 | 슬라이딩 방향 + 도망 경로 예측 |
| **메소** | 한 라운드 (≈ 3~7분) | 관찰 → 설계 → 실행 → 보상 |
| **매크로** | 한 런 (다수 라운드) | 덱 빌드 방향(포탑 종류 / 유틸 / 합성 깊이) |
| **메타** | 런 전체 | 영구 언락 / 신규 카드 풀 (다음 라운드 결정) |

## 3. 핵심 시스템 (Core Mechanics)

### 3.1 환경 퍼즐 — 가구 슬라이딩
- **이동 법칙**: 가구는 한 번 밀면 (상/하/좌/우) **벽이나 다른 오브젝트에 부딪힐 때까지 멈추지 않고 미끄러진다**. 얼음판 슬라이딩 퍼즐 방식.
- **이동 횟수 제한**: 라운드마다 가구 이동 가능 횟수 제한. **잔여 횟수 보너스**(미사용 시 추가 보상) 가능.
- **타일 기반 그리드**: 가구·포탑·바퀴·벽 모두 같은 타일 좌표계. 도망 경로는 타일 거리 기준.

### 3.2 은폐 AI — 바퀴벌레 도망
- **숨어 있는 동안 무공격**: 가구 아래에 들어간 바퀴는 안 움직이고 안 보임.
- **노출 → 즉시 도망**: 가구가 빠져 노출되면 *가장 가까운 다른 가구 밑* 으로 향한다.
- **도망 경로가 곧 Kill Zone**: 플레이어는 도망 경로 위에 포탑 사거리가 걸리도록 가구를 재배치.
- **인지 방식 (TBD)**: 시작 시 표시 / 스캔 액션 / 가구 들어 보기 — 다음 라운드 결정.

### 3.3 전투 시스템

#### 3.3.1 자동 공격 포탑 (Turret)
- 기본 성능은 **의도적으로 매우 제한적** (짧은 사거리, 느린 공속).
- 가구 배치 없이 포탑만으로 클리어 불가능하도록 밸런스.
- 코스트 시스템으로 라운드당 배치 가능 수 제한.

#### 3.3.2 클리커 액션 (Active Skill)
플레이어가 직접 마우스 클릭/터치로 발동하는 쿨타임 스킬. **변수 통제 + 딜 보충** 역할.
- **파리채 타격**: 단일 즉시 처치 / 짧은 쿨.
- **살충제 스프레이**: 범위 둔화 + 약한 지속 피해.
- **일시 정지**: 짧은 시간 시뮬레이션 정지(=배속 0).
- *(이상 예시. 정식 카탈로그는 다음 라운드)*

#### 3.3.3 포탑 카탈로그 (초안)
| 분류 | 예시 | 특성 |
|------|------|------|
| 광범위 | 펄스건 | 넓은 원형 범위, 약한 단발 |
| 장판 | 끈끈이/독장판 | 지속 피해, 둔화 |
| 둔화 | 얼음 타워 | 적 이동 속도↓ |
| 가구 공격 | 미사일 | 가구·바퀴 모두 노릴 수 있음 (변수) |
| **시그니처: 화생방 (전염병) 타워** | — | **한 마리에 묻으면 이동마다 다른 바퀴로 전염, 누적 데미지** |

> **화생방 타워**가 시그니처인 이유: *몰아넣기* 라는 게임의 핵심 행동에 가장 강한 보상을 준다. 한 점에 모이면 폭발한다 = "박멸의 쾌감"의 메커니즘 본체.

### 3.4 덱빌딩 / 로그라이크 (Progression)

#### 3.4.1 라운드 보상 (Drafting)
매 라운드(방) 클리어 후 **상점 등장**. 돈을 내고 카드팩을 구매(Balatro 식).
- **포탑 카드**: 레이저, 펄스건, 미사일, 얼음, 화염방사 등.
- **포탑 강화 카드**: 공격력↑, 연사↑, 관통탄, 독 지속 피해 등.
- **유틸리티 / 스킬 카드**: 가구 이동 횟수↑, 끈끈이 함정, 클릭 스킬 쿨↓, 바퀴 이동 둔화 등.

#### 3.4.2 합성 (Merging)
**동일 타워 + 동일 티어** 두 장을 합치면 1단계 레벨업. 코스트 효율과 깊이의 핵심 빌드 동사.

#### 3.4.3 유틸리티 4슬롯 (글로벌 버프)
런 전체 또는 라운드 내내 적용되는 글로벌 효과. *예: 모든 타워 +10%*. 슬롯 4개 한정 → *무엇을 끼고 무엇을 뺄 것인가* 가 빌드의 정체성.

#### 3.4.4 절차적 맵 생성
매 라운드마다 방 모양·가구 배치/크기·바퀴 스폰 위치가 무작위 변경. 단, 30개 스테이지 *수작업 설계* 와 절차적 변형의 비율은 다음 라운드 결정 사항(리스크 1번 항목).

### 3.5 시간 / 시뮬레이션
- **시뮬레이션 턴제**: 가구 이동 = 1턴. 턴 종료 시 바퀴 도망 + 포탑 발사 + 스킬 처리.
- **슬로우 / 배속 토글**: 관찰·설계 단계에서 슬로우, 실행 단계에서 배속.

## 4. 게임 플레이 루프

### 4.1 한 라운드의 흐름

```
[관찰]   방 구조·가구 배치·바퀴 위치·포탑 카드 패 확인
   ↓
[설계]   포탑 배치 위치 결정 + 가구 슬라이딩 경로 시뮬레이션
   ↓
[실행]   가구 밀기 → 바퀴 노출 → 도망 → 포탑/스킬 자동·수동 발사
   ↓
[정리]   잔여 바퀴 클릭 스킬로 마무리, 잔여 이동 횟수 확인
   ↓
[보상]   카드팩 구매 / 합성 / 유틸 슬롯 갱신
   ↓
[반복]   더 복잡한 다음 방으로
```

### 4.2 마이크로 루프 (가구 1회 이동)
1. 가구 선택 + 방향 결정
2. 슬라이딩 → 멈춤 위치 확정
3. 노출된 바퀴 즉시 도망 경로 계산
4. 포탑 사거리 / 스킬 쿨 비교
5. *이번 한 수가 잔여 횟수 보너스를 깰 가치가 있는가?* 자체 평가

### 4.3 메소 루프 (한 라운드)
관찰 → 설계 → 실행 → 보상의 4단계. 한 라운드 안에서 **모든 핵심 시스템(퍼즐·전투·덱빌딩)이 1회씩 등장**하도록 설계. 최소 단위에서 게임 전체의 재미가 들어맞아야 데모 검증 가능.

### 4.4 매크로 루프 (한 런)
다수 라운드 = 1 런. 빌드 방향(어떤 포탑 축, 어떤 유틸 콤보)이 누적되어 후반 라운드의 정체성이 결정. 합성 깊이와 폭의 트레이드오프가 매크로의 엔진.

## 8. 차별화 지점 (이 게임만의 빈자리)
1. **타워 디펜스가 *경로 게임* 이 되는 순간**: PvZ는 줄, 냥코는 한 줄, 일반 TD는 고정 경로. 우리는 *플레이어가 매 턴 경로를 그린다*.
2. **퍼즐 + 로그라이크의 드문 교차점**: 퍼즐 게임은 보통 정답이 있다 → 우리는 매 라운드 새 방 + 덱이 다르므로 *정답이 매번 달라진다*.
3. **"몰아넣기" 가 시그니처 행동**: 화생방(전염병) 타워가 그 행동을 직접 보상한다. 시그니처 메커닉이 시그니처 감정(쾌감)에 1:1 대응.
4. **5,000원 인디 가격대 + 데모 무아트 검증 가능**: 둘이 만들 수 있는 범위, 회의에서 *비용 구조 적합* 으로 명시 확인된 부분.
