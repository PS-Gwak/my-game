# Project: Roach Exterminator (가제 — 바퀴벌레 섬멸기술)

가구를 밀어 바퀴벌레의 은신처를 무너뜨리고, 동선을 만들어 포탑·스킬로 박멸하는 **퍼즐 + 타워 디펜스 + 덱빌딩 로그라이크 + 클리커**.

## 상태
- **메인 디벨롭 대상 (확정)** — 2026-04-27 회의에서 4종 후보 중 메인으로 선정
- **초기 기획 v0.1** (2026-04-28)
- 핵심 룰(가구 슬라이딩 + 도망 AI + 포탑/스킬 + 덱빌딩) 확정
- 30 스테이지 기믹·바퀴 인지 방식·아트 톤은 다음 라운드(5/1 회의 전까지)

## 핵심 한 줄
> "가구를 밀어 은신처를 부수고, 도망치는 동선을 직접 그려 포탑 사거리로 몰아넣는다. 한 마리도 남기지 않는 박멸의 쾌감 — 5,000원짜리 두뇌 게임."

## 차별점
- **퍼즐과 디펜스의 결합**: 타워를 *어디 짓느냐*가 아니라 *적을 어디로 흘려보내느냐* 가 핵심. 가구(얼음 슬라이딩)가 곧 경로 설계 도구.
- **은폐 AI**: 가구가 빠지면 바퀴벌레는 *가장 가까운 다른 가구* 로 도망 — 도망 경로 자체가 플레이어가 디자인하는 Kill Zone.
- **화생방 타워(전염병)**: 한 마리에 묻으면 이동마다 다른 바퀴에 옮는 시그니처 메커닉. 한 점에 몰아넣을수록 폭발적 시너지.
- **덱빌딩 + 합성**: 매 라운드 카드팩(Balatro 식) 구매, 동일 타워 + 동일 티어 합치면 레벨업, 4슬롯 글로벌 유틸리티.
- **아트 톤**: 스폰지밥 자가닥 카툰 — "안 귀여운 걸 귀엽게."

## 타깃 가격
- **5,000원 이하 / $5 이하** (회의 결정: 인디 가격대 0~3달러대 인지 묶음 활용)

## 강점 (회의 정리)
- 데모 단계에서 **아트 0** 으로도 재미 검증 가능
- 규칙이 명확 → 무엇이 모자란지 보이기 쉬움 → 피드백 사이클 짧음
- 둘이서(동현·일현) 만들 수 있는 비용·범위

## 리스크 / 다음 라운드
- 30개 스테이지 수작업 설계 + 검증 (퍼즐 미경험이 병목)
- 스테이지마다 새 기믹/맵 구조 (가구 모양·기둥·구조 변화)
- 바퀴 위치 인지 방식 결정 (시작 표시 / 스캔 / 가구 들기 등)
- 아트 톤 확정 + 메인 비주얼(가구·드론·로봇·바퀴 대소동, 바텀업 뷰)
