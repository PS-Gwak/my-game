## 0. 대전제 — 모든 룰의 상위 원칙

**한 턴의 순서**:

```
① 가구 이동 → ② 가구 위치 확정 → ③ 바퀴 이동 + 타워 공격 (③은 동시 진행)
```

이 순서가 보장되므로 "가구가 바퀴 위로 미끄러진다", "도망 도중 가구가 사라진다" 같은 충돌 상황은 **물리적으로 발생 불가능**. 룰 모호점들이 이 대전제 하나로 해소됨.

## 1. 데모 1판 룰 한 페이지

### 1.1 게임 기본

| 항목 | 값 |
|---|---|
| 그리드 | 6×6 |
| 가구 | 2개 (1×1 + 2×1 혼합) |
| 고정 장애물 | 기둥 1~2개 |
| 바퀴 | 4마리, 방 중앙에서 산개해 가구 밑으로 숨음 |
| 바퀴 위치 확인 | **Tab 누르고 있는 동안만 보임** (Hold) |
| 이동 횟수 한도 | 6회 |

### 1.2 한 턴의 흐름

```
[행동]  타워 배치 (코스트 한도 2 안에서, 무료 행동)
       + 가구 이동 1번 (이동 횟수 1 차감)
       → 둘 다 같은 턴에 함께 가능
   ↓
①  가구 이동 (얼음 슬라이딩으로 끝까지)
   ↓
②  가구 위치 확정
   ↓
③  바퀴 이동 + 타워 공격 (동시 진행)
```

### 1.3 타워 (2종)

| | 단일공격 연사 | 광범위 |
|---|---|---|
| **코스트** | 1 | 2 |
| **사거리** | 2타일 | 2타일 원형 |
| **공속** | 1턴 2발 | 1턴 1발 |
| **데미지** | 1 | 1 |
| **표적** | 단일 → 첫 발 명중 후 다음 가까운 적 자동 전환 | 범위 안 모든 적 동시 타격 |
| **시작 핸드** | 1장 | 1장 |

- **코스트 한도 2 (한 라운드 누적)** → 광범위(2) OR 단일공격 연사(1) 중 하나만 배치 가능 = 자연스러운 트레이드오프
- **한 번 깔면 회수·이동 불가** (고정)
- **공격 타이밍**: 매 턴 ③ 단계, 가구 슬라이딩으로 바퀴가 노출돼 도망가는 동안

### 1.4 바퀴 도망 AI

- 가구 슬라이딩으로 노출되면 → **가장 가까운 다른 가구**로 도망
- 거리 기준 = **유클리드 거리** (실제 직선 거리)
- 동거리에 여러 가구면 = **가구 ID 순** (배치 순서)
- 갈 가구 없으면 = **아무리 멀어도 어떻게든 가구를 향함**
- 바퀴 속도·HP는 **적 종류별로 다름** (일반 = HP 1, 엘리트 = 다수). *데모 1판에 엘리트 포함 여부는 미정*

### 1.5 승리·패배

| | |
|---|---|
| 승리 | 모든 바퀴 박멸 |
| 패배 | **없음** (퍼즐형, 이동 횟수 다 써도 무한 재시도) |
| 잔여 이동 보너스 | 절반 이하 사용 시 다음 라운드 카드팩 +1 |

### 1.6 데모 구조

- **3판 데모**
  - 1판 = 룰 익히기 (위 1.1~1.5 수치)
  - 2판 = 단일공격·광범위 트레이드오프 부각
  - 3판 = 둘 다 활용해야 하는 조합 시나리오
- **2판·3판 정확한 난이도는 1판 굴려본 뒤 조정**

### 1.7 입력·UX

| 입력 | 동작 |
|---|---|
| 마우스 드래그 | 가구 선택 + 방향 슬라이딩 |
| 클릭 (핸드 카드 → 빈 타일) | 타워 배치 |
| **Tab 누르기 (Hold)** | 바퀴 위치 표시 |
| '실행 전 미리보기' 버튼 | 가구 이동 결과 시뮬레이션 (Undo 대신) |

### 1.8 시각 (데모는 아트 0)

- 도형·이모지·색 블록 (가구 = □, 바퀴 = 🪳, 타워 = ▲)
- 바퀴 죽는 이펙트 = 영혼 올라가는 카툰 톤
- 슬로우/배속 토글 없음 (한 속도 고정)

## 2. 광범위 타워 수치 — 합의 근거

> 광범위는 단일공격 연사와 대비되는 캐릭터. 두 타워 차이가 한 판에 바로 느껴지도록 설계.

| 이유 | 설명 |
|---|---|
| 1. 비교 쉬움 | 사거리·데미지 같게 두고 **공격 방식만 다르게** ("정밀 vs 면적") |
| 2. 코스트 정당화 | 광범위는 2코스트(단일의 2배) → 한 방에 여러 마리 잡아야 정당화 |
| 3. 시그니처 동작 | "가구로 바퀴 몰아넣기 → 광범위 한 방"이 데모의 자랑 동작. 화생방 시그니처가 보류된 자리를 광범위 면적 박멸이 대체 |
| 4. 패널티 균형 | 1턴 1발(단일은 2발)이 광범위의 자연스러운 패널티 — 한 발에 여러 마리 박히는 게 본질 |

## 4. 추가 합의 (체크리스트 이후 객관식으로 정해진 것)

| 항목 | 합의 |
|---|---|
| 한 턴 안 행동 | 타워 배치 + 가구 이동 둘 다 함 (회의록 "아무 때나" 입장) |
| 단일공격 연사 2발째 | 첫 발 명중 후 다음 가까운 적 자동 전환 |
| 타워 회수·이동 | 한 번 깔면 고정 (회수 X) |
| 단일공격 연사 코스트 | 1 |
| 광범위 코스트 | 2 |
| 코스트 한도 | 2 (광범위 OR 단일 중 하나만 한 라운드에) |
| 광범위 수치 | 사거리 2타일 원형, 1턴 1발, 데미지 1, 범위 내 동시 타격 |
| 1판 난이도 | 바퀴 4마리, 이동 횟수 6회 |
