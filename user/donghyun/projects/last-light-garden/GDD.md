# Last Light Garden (가제)
**부제:** 빛은 곧 양식이고, 빛은 곧 적의 길이다

---

## 0. 문서 상태
- 본 문서는 데드라인 익스프레스 변형 게임 기획 후보 중 **안 A**입니다.
- 후보 채택 여부: **킵 (대안 후보, 메인 디벨롭 대상은 안 B)**
- 변형 의도:
  1. 데드라인 익스프레스가 형식상 로그라이트(뱀파이어 서바이버즈류)로 보이는 문제 → 진짜 "고정 지형 디펜스" 형식으로 회귀
  2. 5~10시간 챕터 볼륨 → 인디 스팀 게임 볼륨(2~3시간)으로 경량화

---

## 1. 한 줄 요약 (로그라인)
> "햇빛이 사라진 세계, 마지막 정원을 지키는 식물 수호자. 인공 태양의 밝기를 직접 조절해 자원과 위협을 동시에 *부르는* 라인 디펜스."

데드라인 익스프레스의 "속도 레버"를 *조명 다이얼*로 옮긴 변형입니다.
빠르게 달릴수록 위험하고 자원도 끊긴다는 딜레마 → 밝게 켤수록 자원은 빠르게 모이지만 적도 빛에 끌려 더 많이/빠르게 몰려온다.

---

## 2. 개요 (Vision)
| 항목 | 내용 |
|------|------|
| 장르 | 라인 디펜스 (PvZ식) + 능동 페이스 조절 |
| 시점 | 2D 사이드뷰, 6개 가로 레인 |
| 1런 길이 | **8~12분** (1 스테이지) |
| 전체 클리어 | 2~3시간 (스테이지 18~24개) |
| 가격 타겟 | 2,000~2,500원 |
| 톤 | 어둡지만 동화적. 황무지보다 *고요한 멸망 후 유적* |
| 승리 조건 | 스테이지별 시간 버티기 또는 마지막 적 처치 |
| 패배 조건 | 적이 정원 왼쪽 끝(본진 화분) 도달 |

---

## 3. 절대 규칙 — 빛 다이얼 (The Light Dial)
> **"밝히면 자라고, 자라는 만큼 그림자가 모인다."**

화면 중앙 상단에 *빛 다이얼* (0~3단계)이 있습니다.
데드라인의 속도 레버가 그대로 빛으로 옮겨옵니다.

| 빛 단계 | 자원(햇빛) 생산 | 적 스폰 가속 | 식물 사거리 |
|---------|------------------|---------------|-------------|
| 0 (소등) | 0/sec | 0% | 짧음 (50%) |
| 1 (희미) | 1.0/sec | 1.0배 | 80% |
| 2 (밝음) | 2.5/sec | 1.6배 | 100% |
| 3 (눈부심) | 5.0/sec | 2.5배 | 120% (+사거리 보너스) |

- 빛 단계는 실시간 변경 가능
- **빛↑3단계 5초 유지마다 "과부하" 게이지 +1**, 5에 도달하면 30초간 빛 0단계 강제 (블랙아웃)
- 블랙아웃 동안 적은 멈추지 않고 계속 옴 → 사전 자원 비축 압박

---

## 4. 핵심 시설 (모듈식 약식 적용)
6종 식물. 시너지는 *같은 레인 인접* 한정으로 단순화.

| 식물 | 비용 | 역할 | MVP 수치 |
|------|------|------|-----------|
| 햇살꽃 | 50 | 햇빛 자동 생산 (빛 단계와 별개로 추가 생산) | +0.5/sec |
| 가시덤불 | 100 | 단발 사격 (직선) | DPS 8 |
| 폭포꽃 | 175 | 광역 사격 (3칸) | DPS 5×3 |
| 그늘이끼 | 75 | 인접 식물에 빛 차단 (적이 덜 끌림, 사거리 -10%) | 디버프-버프 양면 |
| 가시벽 | 50 | 방벽 (HP 200) | 적 진행 차단 |
| 야광버섯 | 200 | *4분 후 1회 해금*. 즉시 5초간 빛 +1단계 | 단발 부스트 |

### 시너지 (라인 디펜스 약식 모듈)
- 가시덤불 + 폭포꽃 인접 → 가시덤불 사거리 +1칸
- 그늘이끼 + 햇살꽃 인접 → 햇살꽃 적 어그로 50% 감소
- 가시벽 + 가시덤불 인접 → 가시벽 HP +50

## 5. 적 (3종 + 보스)
| 종 | HP | 행동 | 출현 |
|----|----|------|------|
| 그림자 새 | 20 | 단순 직진, 단단한 식물 회피 | Warm-up부터 |
| 굼뜬 송장 | 80 | 직진, 가시벽 우선 파괴 | 2분~ |
| 빛벌레 | 40 | 빛↑일 때 속도 2배 | 빛 2단계 이상에서만 |
| 거인 (보스) | 400 | 5분 ±10초 1회 등장 | 클라이맥스 |

**적 스폰 공식:** `base × (lightDial / 1.5)` — 라인당. 빛 0단계에선 거의 안 나옴.

## 6. 1런 페이즈 (10분 기준)
| 단계 | 시간 | 의미 |
|------|------|------|
| 발아 | 0:00-1:30 | 햇살꽃 기반 다지기, 적 없음 |
| 정원 확장 | 1:30-4:00 | 첫 적 등장, 빛 다이얼 도입 |
| 그림자 위협 | 4:00-7:00 | 빛벌레 등장, 빛 조절 압박 |
| 거인의 발걸음 | 7:00-9:00 | 보스 등장 |
| 잔존 | 9:00-10:00 | 잔당 처리, 클리어 |

승리: 10분 시간 버티기 또는 보스 처치.
패배: 적이 본진 화분 도달.

## 7. 핵심 재미
- **메인:** 빛 다이얼을 언제 올리고 내릴지의 결단. 자원 압박은 빛↑을 강요하고, 적 압박은 빛↓을 강요한다.
- **보조:** 6식물 빌드 조합. 라인별로 다른 전략 시도 (한 라인은 화력 라인, 다른 라인은 자원 라인).

---

## 8. 데드라인 익스프레스에서 가져온/버린 것
| 가져옴 | 버림 |
|--------|------|
| 능동적 페이스 조절 (속도→빛) | 1+3 모듈 구조 (단순 식물로 대체) |
| 절대 규칙의 양면 딜레마 | 외부+내부 이중 방어 |
| 단발 폭주 메커니즘 (BURNOUT→야광버섯) | 포스트아포 황무지 톤 |
| 4단 출력 구조 | 기차/이동 메커니즘 |

**데드라인 DNA 보존도: 약 30%** — 페이스 조절만 직계, 나머지는 환골탈태.

## 9. 메타 진행 (인디 볼륨)
