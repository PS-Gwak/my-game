# Last Light Garden (가제)

데드라인 익스프레스 변형 게임 기획 후보 **안 A**.

## 상태
- **킵 (대안 후보)** — 메인 디벨롭 대상은 안 B (cinder-bastion)
- 본 안은 비교·회귀용으로 보존

## 핵심 한 줄
> 빛 다이얼을 직접 조절해 자원과 위협을 동시에 부르는 라인 디펜스.

## 차별점 (vs 데드라인 익스프레스)
- 형식: 이동형 → 고정 6레인 라인 디펜스
- 페이스 조절: 속도 레버 → 빛 다이얼
- 볼륨: 5~10시간 챕터 → 1런 8~12분, 전체 2~3시간
- 톤: 황무지 매드맥스 → 동화적 멸망

## 데드라인 DNA 보존도
약 30% (페이스 조절만 직계, 모듈/이중방어/톤은 버림)
