## 0.5. 스토리 셋업 — 30일

황무지 한복판, 거점은 **그동안 SOS 라디오 신호를 송출해왔다.**
누구도 응답하지 않던 그 신호를, 마침내 *누군가가 들었다.*

**1일차, 새벽.**
라디오에서 거친 잡음을 뚫고 한 목소리가 들린다.
> "거점 좌표 잡았다. 30일 뒤 도달한다. 거기서 보자."

같은 황무지를 떠도는 약탈자 본대다.
구원이 아니라 약탈, 식량과 자원, 거점 그 자체가 그들의 목표다.
그들은 **30일 뒤 거점에 도달한다.**

그 사이 매일 밤, 발전기 빛에 이끌려 오는 *선발대* 들이 있다.
원래 SOS 신호가 부른 건 본대 한 팀이 아니다.
황무지에 흩어져 있던 약탈자들 모두가 *어떤 빛*을 향해 다가오고 있었다.

### 플레이어의 임무
30일 뒤 본대가 도착하기 전까지, 매일 밤의 선발대 공세를 견디며
거점을 강화하고, 자원을 모으고, 모듈을 업그레이드하고,
**30일째 본대와 마주할 준비를 한다.**

데드라인 익스프레스의 "기차 한 노드 5분"이 *고정 거점 30일 캠페인* 으로 변환된 직계 변형입니다.
속도 레버 → 발전기 출력 레버. 1+3 모듈 → 발전기 + 외곽 시설 진형.
포스트아포 톤·이중 방어·BURNOUT·절대 규칙 4단 출력 모두 유지.

## 3. 절대 규칙 — 발전기 출력 레버 (The Beacon Throttle)
> **"발전기는 황무지의 등대다. 밝힐수록 약탈자가 모이고, 끌수록 자원이 마른다."**

### 인과 고리
황무지에는 살아남은 거점이 거의 없다. 발전기 가동이 만드는 *소음·진동·열·빛*은 황무지에서 가장 큰 인공 신호이며, 약탈자·돌연변이·다른 세력은 이 신호를 추적해 거점에 몰려든다. 즉 **발전기 출력 = 거점이 외부에 보내는 신호 강도**.

| 변화 | 인과 |
|------|------|
| 출력↑ | 신호 강도↑ → *더 멀리, 더 많이, 더 강한 적*이 거점 인지 → 시설 화력↑ + 자원 채집↑ + 연료·열 부담↑ |
| 출력↓ | 신호 약화 → 적 인지 반경 줄어듦, 신규 스폰 둔화 → 화력↓ + 자원↓ + 연료 절약·열 안정 |
| 출력 0 | *완전한 침묵*. 적이 거점 위치를 잊고 신규 스폰 거의 멈춤. 다만 자원·화력도 정지 |

### 낮과 밤 — 신호의 두 얼굴
- **낮:** 햇빛이 발전기 신호를 *가려준다*. 출력을 올려도 약탈자 인지 반경은 평소의 약 10%에 불과 → 낮에는 적이 거의 안 옴. 자원 채집·열 부담·연료 소모는 그대로 작동하므로, 낮은 *안전한 자원 시간*이자 *정비 시간*이다.
- **밤:** 발전기 빛이 황무지의 *유일한 인공광*이다. 출력 = 신호 강도가 그대로 외부에 노출. 매일 밤 약탈자 선발대가 빛을 따라 몰려온다.

### 4단 출력 표 (밤 기준)

| 출력 | 신호 강도 | 시설 화력 | 자원(고철) 채집 | 연료 소모 | 열 증가 | 적 인지 반경 / 스폰 |
|------|-----------|-----------|------------------|-----------|---------|---------------------|
| 정지 | 무신호 | 50% (수동만) | 0 | 0.5/sec | 0 | 거의 0% (잔존 적 10초 후 흩어짐) |
| 저출력 | 약함 | 75% | 1.0/sec | 1.0/sec | 0.8/sec | 50% |
| 표준 | 강함 | 100% | 1.8/sec | 2.0/sec | 3.2/sec | 100% |
| 과부하 | 폭발적 | 130%+크리 | 3.0/sec | 4.0/sec | 7.2/sec | 180%, *정예·원거리 적 활성화* |

낮에는 같은 출력이라도 적 인지 반경이 10%로 줄어 신규 스폰이 거의 발생하지 않는다. 자원·연료·열 효과는 동일.

- 출력은 실시간 조절 가능, 전투 중에도 변경 가능
- 열 100% = 인접 시설 1개 화재 (15초 DoT)
- 냉각수로 -40% 즉시 대응

### "정지" 상태의 의미
출력 0은 단순한 휴식이 아니라 *전략적 침묵*이다. 시설 화력은 수동 사격만 가능하고 자원 채집도 멈추지만, 적도 거점을 *잊어버려* 신규 스폰이 멈춘다. 이미 진군 중인 적은 자동 후퇴하지 않고 거점 주변을 10초간 배회한 뒤 흩어진다. 즉 정지는 "지금 압박을 끊고 다음 라운드 준비"를 위한 한 박자의 결단이다.

## 4. 모듈 시스템 — 기지 1+3 (모듈식 강하게 유지)
중심부 발전기를 *제외* 하고, 8방향 슬롯에 3종 모듈을 자유롭게 배치/이동.

| 모듈 | HP | 역할 | 시너지 |
|------|-----|------|--------|
| 발전기 (중심) | 300 | 출력 레버, 게임 오버 조건 | - |
| 전투 모듈 | 120 | 자기 방향 사격 (DPS = 출력×기본) | 인접 정비와 결합 시 사거리 +30% |
| 정비 모듈 | 100 | 인접 모듈 회복 (+5HP/sec), 냉각 1.5배 | 정비 2개 인접 시 회복량 2배 |
| 채집 모듈 | 80 | 자기 방향 자원 흡입 (반경 = 출력 반비례) | 인접 채집 시 흡입 반경 +20% |

배치는 8방향(N/NE/E/SE/S/SW/W/NW). 모듈은 *낮 정비 단계*에서 자유 재배치.

### 모듈 철학 (데드라인 직계)
- 발전기는 생존의 심장이다.
- 전투 모듈은 밖을 향한 이빨이다.
- 정비 모듈은 안쪽에서 버티게 하는 손이다.
- 채집 모듈은 출력을 낮출 이유를 만든다.

## 5. 자원 시스템

### 자동 채집 (출력 연동)
- 채집 모듈 자기 방향 흡입 반경은 *출력 반비례*
- 출력 0/1/2/3 = 흡입 반경 220 / 160 / 100 / 0 px
- 자원을 모으려면 출력을 낮춰야 하고, 출력을 낮추면 화력도 떨어진다 (*낮에는 이 갈등이 약해짐*)

### 자원 종류
| 자원 | 용도 |
|------|------|
| 고철 (Scrap) | 모듈 외벽 수리. 고철 10 = 장갑 +20 |
| 연료 (Fuel) | 발전기 가동 필수. 0이면 게임 오버 |
| 냉각수 (Coolant) | 열 -40% 즉시 냉각. 시작 2개, 최대 4개 |

## 6. 적 (5종 + 보스 2종)

### 적 등장 — 일별 점진 강도
30일을 거치며 적 풀이 점진적으로 확장된다. 초반엔 잡몹만, 후반엔 정예와 본대 선봉.

| 종 | HP | 행동 | 출현 일자 |
|----|----|------|-----------|
| 약탈자 | 30 | 단순 돌격, 단발 사격 | 1일~ |
| 사막 벌레 | 80 | 잠복 후 점프 (1방향 무력화) | 5일~ |
| 화염 던지기 | 50 | 원거리, 시설 우선 화재 | 10일~ |
| 코뿔 트럭 | 200 | 정면 돌진 | 15일~ (*출력 표준 임계 트리거*) |
| 박격포 | 70 | 사거리 밖 곡사 (출력↑일수록 명중↑) | 20일~ (*출력 과부하 5초 유지 시 활성화*) |
| 거인 군주 (선봉 보스) | 600 | 25일·28일 야간 1회씩 등장 | 25일, 28일 |
| 강철 군주 (본대 두목) | 1200 | **30일 야간 최종 결전** | 30일 |

### 등장 로직
- **잡몹** (약탈자·벌레·화염): 일자(시간)와 출력의 결합. 매일 밤 등장. 후반 일자일수록 베이스 강도·스폰 속도↑
- **정예·원거리** (코뿔 트럭·박격포): *출력 임계 트리거*. 출력을 임계 미만으로 낮추면 추가 스폰 멈춤. 이미 도착한 개체는 그대로 처리해야 함
- **선봉 보스** (거인 군주): 25일·28일 야간에 한 번씩 등장. 출력 무관. 본대 도착 직전의 압박 강화
- **본대 두목** (강철 군주): 30일 야간 = 캠페인 최종전. 모든 잡몹·정예와 함께 사방 진군

스폰 레이트 공식 (잡몹 야간): `base × (output / 1.5)` 마리/초, base는 그날의 일자에 따라 0.3 → 3.5로 증가.

### 30일째 본대 도착
- 30일 새벽: 정비 시간 0 (낮 페이즈 생략, 즉시 야간 진입). 마지막 라디오 통신 컷씬.
- 30일 야간: 강철 군주 + 누적된 모든 적 종이 8방향 동시 진군
- 강철 군주 처치 = 캠페인 클리어 (엔딩)

## 7. 이중 방어 (외부+내부) — 데드라인 직계 유지
- **외부:** 사방 시설로 적 격퇴 (출력에 따라 자동/수동 화력 변동)
  - 마우스 클릭 지속: 수동 사격 DPS 100% + 크리 25%
  - 손 떼면 자동: DPS 60%, 크리 없음
- **내부:** 외벽 0이 된 모듈은 *침입자* 출현. `Tab`으로 내부 모드 전환 후 사격
  - 내부 모드 동안 외부 자동 포탑 효율 60%로 유지
- **격리벽 `Q`:** 침입 모듈 30초 봉쇄, 그 동안 기능 정지

## 8. 캠페인 구조 — 30일 카운트다운

### 일별 사이클: 낮 → 밤 → 새벽

```
[낮 시작]  (약 1.5분)
   │
   ├─ 외벽 장갑 수리
   ├─ 모듈 재배치 (8방향 슬롯 자유 변경)
   ├─ 정찰 임무 파견 (다음 밤에 결과 반영)
   ├─ 자원 거래 (잔존 NPC 등장 시)
   └─ 모듈 업그레이드 (정해진 일자에 해금)
   │
[해 짐, 밤 시작]  (약 4.5분)
   │
   ├─ 약탈자 선발대 공세 (출력 레버 + 외부/내부 방어)
   ├─ 정예/원거리 등장 (출력 임계 시)
   ├─ BURNOUT 1회 사용 가능
   └─ 라디오 통신 (특정 일자 이벤트)
   │
[새벽]  →  자동 세이브  →  다음 일자 (낮)
```

### 30일 페이즈 분할
| 단계 | 일자 | 의미 |
|------|------|------|
| 정착 | 1~7일 | 약탈자만 등장. 출력 레버·낮밤 사이클 익히기 |
| 다양화 | 8~14일 | 사막 벌레·화염 던지기 등장. 자원 압박 시작 |
| 결단 | 15~21일 | 코뿔 트럭 (출력 임계). 모듈 손상 누적 |
| 본대 선봉 | 22~29일 | 박격포 등장, 25일·28일 거인 군주 야간 등장 |
| **본대 결전** | **30일** | 강철 군주 + 모든 적 동시 진군. 캠페인 최종전 |

### BURNOUT (매일 밤 1회)
- 밤 진입 즉시 해금 (낮은 사용 불가)
- 효과: 5초간 출력 +1단계 무료, 화력 2배, 적 명중 -50%
- 종료 후 무작위 모듈 강제 화재 (15초 DoT)
- 의도: "오늘 밤의 한 방"의 결단 압박. 데드라인 익스프레스의 *4분 후 1회*에서 *매일 밤 1회 리셋*으로 재해석

### 라디오 통신 시스템
스토리 비트는 라디오로 전달된다.
- **1일차 새벽:** 본대의 첫 통신 ("30일 뒤 도착")
- **7일차:** 잔존 NPC 등장 (자원 거래 해금)
- **15일차:** 본대로부터 추가 통신 (본대 규모 정보)
- **25일차:** 거인 군주 첫 야간 도래 예고
- **30일차 새벽:** 본대 도착 직전 마지막 통신

라디오는 사용자 의지와 무관하게 발생하지만, 일별 변형 사건(추가 미정 항목)을 통해 분기 가능.

## 9. 핵심 재미 (4층 루프)

### 마이크로 (밤 중 3~10초)
출력 조절 ↔ 자원/화력/열 변화 ↔ 적 격퇴 ↔ 침입 대응

### 메소 (1일 = 약 6분)
낮 정비 → 밤 전투 → 새벽 → 다음 낮

### 매크로 (캠페인 30일 ≈ 3시간)
1주차 정착 → 2주차 다양화 → 3주차 결단 → 4주차 본대 선봉 → **30일 결전**

### 메타 (캠페인 사이)
캠페인 1회 클리어 후 NG+ 모드 또는 새 시드 (구체 형식은 §11 참조)

### 시한부 압박 — 매 결정의 무게
*"30일 뒤 본대가 온다"*는 사실이 매 결정의 무게를 다르게 만든다.
- **5일차:** "아직 시간 있어, 출력 낮춰서 자원 비축하자"
- **15일차:** "코뿔 트럭이 등장했다, 출력 표준 이상은 위험한 상황"
- **25일차:** "거인 군주 첫 등장, 모듈 업그레이드도 끝내야 하는데 자원이 부족"
- **29일차:** "내일이 본대다. 모든 자원·BURNOUT·모듈을 다 풀어둬야 한다"

## 12. 메타 진행 (인디 볼륨 - 갱신)

### 캠페인 메인 콘텐츠
- 캠페인 1회 = 30일 ≈ 3시간 = 메인 콘텐츠
- 자동 세이브 (매일 새벽 체크포인트)
- 패배 시 그날 새벽부터 재시도

### 캠페인 사이 — 미정 결정사항
다음 중 하나로 결정 필요:
- (A) **단편 내러티브** — 1회 클리어로 게임 완료. 도전 모드 추가 정도
- (B) **NG+ 반복** — 클리어 시 적 강화·자원 감소된 새 캠페인 (Hades식)
- (C) **시드 로그라이트** — 매 캠페인 시작 거점·모듈 변종 무작위 (Slay the Spire식)

### 모듈 변종 (해금 콘텐츠)
- 전투 변종 3종, 정비 변종 2종, 채집 변종 2종 (총 7종)
- 캠페인 진행/클리어로 단계적 해금
