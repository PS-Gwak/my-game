# Cinder Bastion (가제)
**부제:** 마지막 발전기를 둘러싼 360도의 결단

---

## 0. 문서 상태
- 본 문서는 데드라인 익스프레스 변형 게임 기획 후보 중 **안 B**입니다.
- 후보 채택 여부: **메인 디벨롭 대상 (선택됨)**
- 변형 의도:
  1. 데드라인 익스프레스가 형식상 로그라이트(뱀파이어 서바이버즈류)로 보이는 문제 → 진짜 "고정 지형 디펜스" 형식으로 회귀
  2. 5~10시간 챕터 볼륨 → 인디 스팀 게임 볼륨(5~7시간)으로 경량화
- 데드라인 DNA 직계 변형이라 페이스/모듈/이중방어/톤/BURNOUT 모두 유지

---

## 1. 한 줄 요약 (로그라인)
> "황무지 한복판, 발전기 하나로 버티는 외딴 거점. 발전기 출력 레버가 곧 너의 무기이자 너의 적을 부르는 신호다 — 사방 8방향에서 몰려오는 약탈자를 막아내라."

데드라인 익스프레스의 "기차"가 멈춘 채 *최후 거점* 으로 변환된 직계 변형입니다.
속도 레버 → 발전기 출력 레버. 1+3 모듈 → 발전기 + 외곽 시설 진형.
포스트아포 톤·이중 방어·BURNOUT 모두 유지.

| 장르 | 원형/사방위 디펜스 + 능동 페이스 조절 + 모듈 시너지 |

## 3. 절대 규칙 — 발전기 출력 레버 (The Beacon Throttle)
> **"발전기는 황무지의 등대다. 밝힐수록 약탈자가 모이고, 끌수록 자원이 마른다."**

### 인과 고리
황무지에는 살아남은 거점이 거의 없다. 발전기 가동이 만드는 *소음·진동·열·빛*은 황무지에서 가장 큰 인공 신호이며, 약탈자·돌연변이·다른 세력은 이 신호를 추적해 거점에 몰려든다. 즉 **발전기 출력 = 거점이 외부에 보내는 신호 강도**.

| 변화 | 인과 |
|------|------|
| 출력↑ | 신호 강도↑ → *더 멀리, 더 많이, 더 강한 적*이 거점 인지 → 시설 화력↑ + 자원 채집↑ + 연료·열 부담↑ |
| 출력↓ | 신호 약화 → 적 인지 반경 줄어듦, 신규 스폰 둔화 → 화력↓ + 자원↓ + 연료 절약·열 안정 |
| 출력 0 | *완전한 침묵*. 적이 거점 위치를 잊고 신규 스폰 거의 멈춤. 다만 자원·화력도 정지 |

이것이 게임의 양면 딜레마다.
- 빠르게 모으려면 신호를 강하게 → 적이 밀려옴
- 살아남으려면 신호를 줄임 → 자원과 화력을 잃음

### 4단 출력 표

| 출력 | 신호 강도 | 시설 화력 | 자원(고철) 채집 | 연료 소모 | 열 증가 | 적 인지 반경 / 스폰 |
|------|-----------|-----------|------------------|-----------|---------|---------------------|
| 정지 | 무신호 | 50% (수동만) | 0 | 0.5/sec | 0 | 거의 0% (잔존 적은 10초 후 흩어짐) |
| 저출력 | 약함 | 75% | 1.0/sec | 1.0/sec | 0.8/sec | 50% |
| 표준 | 강함 | 100% | 1.8/sec | 2.0/sec | 3.2/sec | 100% |
| 과부하 | 폭발적 | 130%+크리 | 3.0/sec | 4.0/sec | 7.2/sec | 180%, *정예·원거리 적 활성화* |

- 출력은 실시간 조절 가능, 전투 중에도 변경 가능
- 열 100% = 인접 시설 1개 화재 (15초 DoT)
- 냉각수로 -40% 즉시 대응

### "정지" 상태의 의미
출력 0은 단순한 휴식이 아니라 *전략적 침묵*이다. 시설 화력은 수동 사격만 가능하고 자원 채집도 멈추지만, 적도 거점을 *잊어버려* 신규 스폰이 멈춘다. 이미 진군 중인 적은 자동 후퇴하지 않고 거점 주변을 10초간 배회한 뒤 흩어진다. 즉 정지는 "지금 압박을 끊고 다음 라운드 준비"를 위한 한 박자의 결단이다.

## 4. 모듈 시스템 — 기지 1+3 (모듈식 강하게 유지)
중심부 발전기를 *제외* 하고, 8방향 슬롯에 3종 모듈을 자유롭게 배치/이동.

| 모듈 | HP | 역할 | 시너지 |
|------|-----|------|--------|
| 발전기 (중심) | 300 | 출력 레버, 게임 오버 조건 | - |
| 전투 모듈 | 120 | 자기 방향 사격 (DPS = 출력×기본) | 인접 정비와 결합 시 사거리 +30% |
| 정비 모듈 | 100 | 인접 모듈 회복 (+5HP/sec), 냉각 1.5배 | 정비 2개 인접 시 회복량 2배 |
| 채집 모듈 | 80 | 자기 방향 자원 흡입 (반경 = 출력 반비례) | 인접 채집 시 흡입 반경 +20% |

배치는 8방향(N/NE/E/SE/S/SW/W/NW). 모듈은 정비 단계에서 자유 재배치.

### 모듈 철학 (데드라인 직계)
- 발전기는 생존의 심장이다.
- 전투 모듈은 밖을 향한 이빨이다.
- 정비 모듈은 안쪽에서 버티게 하는 손이다.
- 채집 모듈은 출력을 낮출 이유를 만든다.

---

## 5. 자원 시스템
### 자동 채집 (출력 연동)
- 채집 모듈 자기 방향 흡입 반경은 *출력 반비례*
- 출력 0/1/2/3 = 흡입 반경 220 / 160 / 100 / 0 px
- 즉, 자원을 모으려면 출력을 낮춰야 하고, 출력을 낮추면 화력도 떨어진다

### 자원 종류
| 자원 | 용도 |
|------|------|
| 고철 (Scrap) | 모듈 외벽 수리. 고철 10 = 장갑 +20 |
| 연료 (Fuel) | 발전기 가동 필수. 0이면 게임 오버 |
| 냉각수 (Coolant) | 열 -40% 즉시 냉각. 시작 2개, 최대 4개 |

## 6. 적 (5종 + 보스 2종)
| 종 | HP | 행동 | 출현 조건 |
|----|----|------|-----------|
| 약탈자 | 30 | 단순 돌격, 단발 사격 | 출력 1 이상 시 처음부터 |
| 사막 벌레 | 80 | 잠복 후 점프 (1방향 무력화) | 5분~, 출력 1 이상 |
| 화염 던지기 | 50 | 원거리, 시설 우선 화재 | 8분~, 출력 2 이상 |
| 코뿔 트럭 | 200 | 정면 돌진 | 12분~, *출력 표준(2) 임계 트리거* |
| 박격포 | 70 | 사거리 밖 곡사 (출력↑일수록 명중↑) | *출력 과부하(3) 5초 유지 시 활성화* |
| 거인 군주 (보스) | 600 | 노드 마지막 1회 등장 | 18~22분 (출력 무관) |
| 강철 군주 (보스) | 1200 | 최종 노드 | 최종 (출력 무관) |

### 등장 로직
- **일반 잡몹 (약탈자·벌레)**: *시간 + 출력*의 결합. 시간이 지날수록 베이스 강도가 오르고, 출력이 인지 반경·스폰 페이스에 직접 영향.
- **정예·원거리 (코뿔 트럭·박격포)**: *출력 임계*가 트리거. 출력을 임계 미만으로 낮추면 추가 등장이 멈추지만, 이미 도착한 개체는 그대로 처리해야 함.
- **보스**: 노드 진행 단계 기반(출력 무관). 다만 등장 후 거점 도달 속도는 출력↑일수록 빨라짐.
- **출력 0 (정지)**: 적 인지 반경 거의 0 → 신규 스폰 멈춤. 진군 중인 적은 10초간 거점 주변 배회 후 흩어짐 (자동 후퇴 아님).

스폰 레이트 공식 (잡몹): `base × (output / 1.5)` 마리/초, base는 노드 시간(분)에 따라 0.3 → 3.5로 증가.

## 7. 이중 방어 (외부+내부) — 데드라인 직계 유지
- **외부:** 사방 시설로 적 격퇴 (출력에 따라 자동/수동 화력 변동)
  - 마우스 클릭 지속: 수동 사격 DPS 100% + 크리 25%
  - 손 떼면 자동: DPS 60%, 크리 없음
- **내부:** 외벽 0이 된 모듈은 *침입자* 출현. `Tab`으로 내부 모드 전환 후 사격
  - 내부 모드 동안 외부 자동 포탑 효율 60%로 유지
- **격리벽 `Q`:** 침입 모듈 30초 봉쇄, 그 동안 기능 정지

## 8. 1런 페이즈 (25분 기준)
| 단계 | 시간 | 의미 |
|------|------|------|
| 정찰 | 0:00-3:00 | 단일 약탈자, 출력 익히기 |
| 압박 | 3:00-9:00 | 적 종 추가, 첫 모듈 손상 |
| 결단 | 9:00-15:00 | 출력↑ 강요 vs 자원↓ 위험 |
| 클라이맥스 | 15:00-22:00 | 보스 + 군중, BURNOUT 해금 |
| 잔존 | 22:00-25:00 | 잔당, 다음 노드 결정 |

### BURNOUT (4분 1회 해금)
- 5초간 출력 +1단계 무료 (열·연료 추가 소모 없음)
- 화력 2배, 적 명중 -50%
- 종료 후 무작위 모듈 강제 화재 (15초 DoT)
- 의도: "화끈한 한 방 + 후유증 관리" — 데드라인 그대로

## 9. 핵심 재미
- **메인:** 출력 레버의 입력 긴장감. 데드라인 익스프레스의 핵심 그대로.
- **보조:** 8방향 모듈 배치의 공간 의사결정 (어느 방향에 화력? 정비? 채집?). 노드 사이 정비 단계에서의 빌드 진화.
- **메타:** 노드 분기 (지름길/우회로), 영구 업그레이드.

### 입력 매핑
| 입력 | 동작 |
|------|------|
| 0 / 1 / 2 / 3 | 출력 단계 |
| 마우스 좌클릭 | 수동 사격 |
| Tab | 내부 모드 전환 |
| Q | 격리벽 (침입 모듈 봉쇄) |
| C | 냉각수 사용 |
| Space | BURNOUT (4분 해금 후 1회) |
