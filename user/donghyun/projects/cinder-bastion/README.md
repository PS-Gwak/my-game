# Cinder Bastion (가제)

데드라인 익스프레스 변형 게임 기획 후보 **안 B**.

## 상태
- **메인 디벨롭 대상 (선택됨)**
- 본 안을 중심으로 GDD 디테일 작업 진행 예정

## 핵심 한 줄
> 발전기 출력 레버를 직접 조절해 자원과 위협을 동시에 부르는 360도 사방위 디펜스.

## 차별점 (vs 데드라인 익스프레스)
- 형식: 이동형 사이드뷰 → 정착형 탑다운 8방향
- 페이스 조절: 속도 레버 → 발전기 출력 레버 (구조 동일)
- 볼륨: 5~10시간 챕터 → 1런 20~30분, 전체 5~7시간
- 톤·이중방어·BURNOUT·1+3 모듈은 모두 유지

## 데드라인 DNA 보존도
약 80% (페이스+모듈+이중방어+톤+BURNOUT 모두 직계)
