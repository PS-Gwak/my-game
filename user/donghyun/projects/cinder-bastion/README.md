# Cinder Bastion (가제)

데드라인 익스프레스 변형 게임 기획 후보 **안 B**.

## 상태
- **메인 디벨롭 대상 (선택됨)**
- 본 안을 중심으로 GDD 디테일 작업 진행 예정

## 핵심 한 줄
> 30일 뒤 본대가 도착한다. 매일 낮은 정비, 매일 밤은 발전기 빛에 끌려오는 약탈자와의 전투. 출력 레버 하나로 자원·화력·위협을 30일 동안 버텨내고 본대 결전을 맞이하라.

## 차별점 (vs 데드라인 익스프레스)
- 형식: 이동형 사이드뷰 → 정착형 탑다운 8방향
- 페이스 조절: 속도 레버 → 발전기 출력 레버 (구조 동일, 낮/밤 분기 추가)
- 시간축: 5분 1노드 → **30일 카운트다운 캠페인 (1일 = 약 6분, 전체 약 3시간)**
- 매일 = 낮(정비) + 밤(전투) 사이클
- 30일째 = 본대 도착 = 강철 군주 최종전
- 톤·이중방어·BURNOUT·1+3 모듈은 모두 유지 (BURNOUT은 매일 밤 1회 리셋으로 재해석)

## 데드라인 DNA 보존도
약 80% (페이스+모듈+이중방어+톤+BURNOUT 모두 직계, 시한부 카운트다운은 강화)
