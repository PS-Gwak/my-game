# Operation: Burrow (가제)

두더지 게임 + 정밀 저격이 충돌하는 사이드뷰 슈터 기획안.

## 상태
- **초기 기획 v0.1** (2026-04-27)
- 시점·톤·시그니처 메커닉·핵심 규칙 확정
- 진행 구조(웨이브 / 로그라이트 / 스토리)·적 카탈로그·사운드 디자인은 다음 라운드

## 핵심 한 줄
> "3발의 탄창, 3타격의 체력, 7개의 구멍. 두더지처럼 솟아오르는 적 저격수들 사이에서, 단 한 발 한 발의 우선순위를 가려내는 사이드뷰 결투."

## 차별점 (vs 기존 두더지·저격 장르)
- **사이드뷰 + 스코프 토글**: 평소엔 7구멍을 한눈에, 우클릭으로 1인칭 스코프(시간 0.3배속) 진입
- **3발 탄창 압박**: 동시 등장 적 최대 3명 + 탄 3발 = 매 호흡이 결단
- **풀 재장전 vs 캔슬 재장전**: R 키 하나에 두 가지 의미 (2초 무방비/3발 vs 0.7초/1발)
- **공격 카운트다운(Telegraphing)**: 적은 등장 즉시 못 쏨, 1.2초 빨간 레이저 후 발사 → 두더지 게임의 노출 윈도우 그대로
- **명중 위계 3단**: 일반 충격파 / 보너스 슬로우 / 하이라이트 X-Ray 킬 캠

## 영감 받은 게임 (취사선택)
- **Hitman: Sniper** — 한 자리에서 모든 타겟 처리 (취함)
- **Sniper Elite** — X-Ray 킬 캠의 임팩트 (취함)
- **Superhot** — 스코프 진입 시 시간 슬로우 (취함)
- **Receiver** — 재장전을 게임성의 핵으로 (캐주얼하게 압축해서 취함)
- **House of the Dead** — 디코이/우선순위 판단의 원형 (취함)
- 라이트건 강제 카메라 이동 / 캐주얼 두더지 무한 탭은 **버림**
