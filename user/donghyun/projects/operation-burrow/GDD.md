# Operation: Burrow (가제)
**부제:** 7개의 구멍, 3발의 탄창

---

## 0. 문서 상태
- 두더지 게임 + 정밀 저격 결합 기획안
- 현재 버전: **v0.1 초기 기획** (2026-04-27)
- 핵심 4축(시점·톤·시그니처·규칙) 확정 단계

## 1. 컨셉 한 줄 + 개요

### 1.1 로그라인
> **"3발의 탄창, 3타격의 체력, 7개의 구멍. 두더지처럼 솟아오르는 적 저격수들 사이에서 단 한 발 한 발의 우선순위를 가려내는 사이드뷰 결투."**

### 1.2 게임 한 줄 정의
*Hitman: Sniper의 정밀함 × Pistol Whip의 리듬 × 두더지 게임의 압박* — 한 화면 위에서 펼쳐지는 한 호흡의 결정 게임.

### 1.3 개요 (Vision)
| 항목 | 내용 |
|------|------|
| 장르 | 사이드뷰 정밀 슈터 + 두더지 리듬 + 다중 위협 우선순위 |
| 시점 | 2.5D 사이드뷰 / 우클릭으로 1인칭 스코프 토글 |
| 기본 단위 | 1웨이브 ≈ 60~90초 (잠정) |
| 세션 길이 | PC 인디 / 1판 약 5~15분 (잠정) |
| 톤 | 쿨한 밀리터리 — *Operation: Burrow* (한밤의 적 기지) |
| 시그니처 | 한 발의 무게감 × 다중 위협 |
| 승리 조건 | 미정 (진행 구조 결정 후) |
| 패배 조건 | 체력 0 (4회 피격) |

## 2. 핵심 재미

### 2.1 시그니처 — 한 발의 무게감 × 다중 위협
탄창은 부족하고 적은 넘친다. 동시 등장 적 최대 3명 + 탄 3발이 만들어내는 압축된 딜레마. 매 발사 직전 *"누구를 먼저 쏠 것인가"*, 매 재장전 직전 *"풀로 갈까, 1발만 빠르게 갈까"* 라는 결단이 게임 전체의 엔진.

### 2.2 메인 재미 — R 키 하나의 두 의미
- **풀 재장전 (R)**: 2초 무방비, 3발 채움. *"적이 잠잠한 한 박자"* 가 필요한 선택.
- **캔슬 재장전 (R + 우클릭, 0.7초 시점)**: 0.7초 무방비, 1발만 약실에 장전. *"지금 당장 한 발이 급하다"* 일 때.

새 키·새 UI 없이 기존 입력에 의미만 추가한 **레이어링(Layering)** 설계. 학습 부담 거의 없이 결정의 깊이만 늘림. 실제 볼트액션 저격소총의 *매거진 교체 vs 약실 직접 장전* 행동을 게임화.

### 2.3 정보 우위와 시간 우위의 비대칭
- **플레이어**: 7구멍 한눈에 (정보 우위). 항상 노출됨 (시간 불리).
- **적**: 자기 구멍 시야만 (정보 불리). 등장 후 1.2초 카운트다운 후 발사 (시간 유리).

플레이어가 "내려다보는 사령관"의 시야 우위로 적의 *시간 유리*를 상쇄하는 비대칭 구조.

### 2.4 결단의 순간들 (대표 시나리오)

**시나리오 A — "탄 0발, 적 RPG, 1초"**
> 탄창 0/3. 구멍 #4에서 RPG병이 1초 후 발사. 다른 구멍 잠잠.
> R 풀 재장전(2초)이면 RPG에 맞아 체력 -1. R+우클릭 캔슬(0.7초)이면 1발 장전 → 처치 → 체력 보존.
> 단, 곧 #6에서 다음 적 등장. 또 0발. *또* 캔슬할 것인가, *이제는* 풀 재장전을 결단할 것인가?

**시나리오 B — "동시 3 위협, 디코이 1, 탄 2발"**
> 구멍 #1·#3·#5에서 RPG병·저격수·디코이(아군 포로) 동시 등장. 탄 2발.
> 디코이 쏘면 감점, RPG는 즉사 위협, 저격수는 1.5초 카운트다운.
> "C(보너스 두더지)를 먼저 잡고 재장전 vs 위협 두 명을 처리하고 빈 탄창으로 버티기" — 어느 쪽도 정답이 아니다.

**시나리오 C — "엄폐물 1발 남았다"**
> 모래주머니 흡수량 1/2 남음. 곧 RPG 발사. 스코프 진입 시간이 부족.
> 모래주머니로 한 발 흡수하고 재장전할 것인가, 무리해서 노스코프로 1발 쏠 것인가?

### 2.5 4층 플레이 순환

| 층위 | 주기 | 결정 단위 |
|------|------|-----------|
| **마이크로** | 0.5~3초 | 인지 → 판별 → 사격 / 재장전 결단 |
| **메소** | 15~30초 | 한 호흡 (3발 + 재장전 + 위협 정리) |
| **매크로** | 60~90초 | 한 웨이브 (체력·엄폐물 관리, 페이즈 변화) |
| **메타** | (TBD) | 진행 구조 결정 후 — 메타 성장 / 무기 언락 등 |

## 3. 규칙 — 절대 규칙

### 3.1 탄창과 재장전 (Magazine & Reload)

| 입력 | 시간 | 결과 | 적합한 상황 |
|------|------|------|-------------|
| **R (풀 재장전)** | 2.0초 무방비 | 탄 0 → 3 | 적이 잠잠한 한 박자 |
| **R + 우클릭(0.7초 시점)** | 0.7초 무방비 | 탄 0 → 1 | 지금 한 발이 급할 때 |

> 캔슬 재장전이 *항상 정답*인 것처럼 보이지만, 0.7초 캔슬을 두 번 = 1.4초로 풀 재장전(2초)에 가까워지고, *그 사이 다음 적이 등장하면* 더 손해. 자동 정답이 아닌 게 밸런스 핵심.

### 3.2 사격 시스템

| 입력 | 동작 |
|------|------|
| **우클릭 (Hold)** | 스코프 진입 — 시간 0.3배속, 시야 좁아짐, 호흡 사운드 |
| **좌클릭** | 발사 |
| **R** | 재장전 (위 표 참조) |

스코프 진입 시 *유일한* 시간 슬로우. 별도 보조 무기·스킬·게이지 없음. **시그니처(탄창 압박) 순도 유지**.

### 3.3 적 등장 사이클 (Telegraphing)

```
[등장]   0.3초  머리만 절반 노출 — 무공격, 처치 가능
[조준]   1.2초  빨간 레이저 표시 — 카운트다운 시작
[발사]   0.1초  카운트다운 끝, 안 처리하면 피격
[은폐]   0.5초  다시 숨음
─────────────────────────────────
총 노출 약 1.5~2.0초 = 플레이어의 반응 윈도우
```

### 3.4 체력과 페널티
- 체력 3타격 (4회 피격 시 라운드 실패)
- 직격 = -1, 엄폐물 흡수 시 -0
- 디코이 오사 = 감점 또는 위협 가속(잠정)

### 3.5 비대칭 균형 4종 (필수 + 선택)
| 조절 요소 | 설명 | 채택 |
|-----------|------|------|
| 적 공격 카운트다운 (Telegraphing) | 1.2초 빨간 레이저 윈도우 | ✅ 필수 |
| 적 시야 비대칭 | 자기 구멍 시야만, 플레이어는 7구멍 전체 | ✅ 필수 |
| 모래주머니 엄폐물 | 부서지는 엄폐물, 1~2발 흡수 후 파괴 | ✅ 채택 |
| 동시 위협 적 수 제한 | 공격 중인 적 최대 3명 (디코이는 무제한) | ✅ 필수 |
| (대안) 숙이기 / 위치 전환 | 액션감 ↑ 이지만 입력 충돌 우려 | ❌ 보류 |

### 3.6 명중 연출 위계 (3단계)

| 트리거 | 연출 | 시간 |
|--------|------|------|
| 일반 명중 | 충격파 세이브 (화면 정지 + 베이스 사운드) | 0.2초 |
| 보너스 (헤드샷·고위협 처치) | 약한 슬로우 + 줌 흡입 | 0.5초 |
| 하이라이트 (관통·연쇄) | X-Ray 킬 캠 (Sniper Elite 풍) | 1.5초 |

희소성을 유지해야 X-Ray가 매번 카타르시스로 작동. 발생 빈도는 일반 ≫ 보너스 ≫ 하이라이트.

## 4. 게임 루프

### 4.1 한 라운드의 흐름 (15초 시뮬레이션)

```
0.0s  │ 사이드뷰. 한밤의 적 기지. 7구멍. 탄 3/3, 체력 3/3.
2.0s  │ 구멍 #2 페인트(머리만). 압박만.
3.0s  │ #4 빨간 레이저(저격수) + #7 회색(정찰, 무공격) 동시 등장.
4.0s  │ 우클릭 스코프 진입 → 시간 0.3배속.
5.5s  │ 저격수 발사. 충격파 세이브. 탄 2/3.
6.0s  │ 스코프 OUT. #1·#3·#5 동시: RPG·저격수·디코이.
9.5s  │ RPG 헤드샷 → X-Ray 킬 캠. 탄 1/3.
11.0s │ 저격수 카운트 0.3초 남음. 마지막 1발로 처치. 탄 0/3.
12.0s │ #6 새 적. R 누름.
12.7s │ 우클릭 캔슬 → 1발 장전. 즉시 처치. 탄 0/1 → 0/0.
14.0s │ 풀 재장전 R. 2초 후 3/3. 다음 웨이브.
```

### 4.2 마이크로 루프 (0.5~3초)

```
   ┌─────────────────────────────────────────────┐
   │  [인지] 7구멍 스캔                          │
   │     ↓                                       │
   │  [판별] 빨강(위협) / 회색(무시) / 디코이    │
   │     ↓                                       │
   │  [우선순위] 카운트다운 짧은 것 먼저         │
   │     ↓                                       │
   │  [스코프 진입] 우클릭 → 시간 슬로우         │
   │     ↓                                       │
   │  [발사] 좌클릭 → 명중 연출(3단계)           │
   │     ↓                                       │
   │  [재장전 결단] 풀(R) vs 캔슬(R+우클릭)      │
   │     ↓                                       │
   │  ↻ 다음 위협으로                            │
   └─────────────────────────────────────────────┘
```

### 4.3 메소 루프 (15~30초 / 한 호흡)
3발의 탄창을 다 쓰고 → 재장전 결단 → 다음 3발의 사이클까지를 *한 호흡*으로 묶는다. 이 단위가 게임의 *리듬*을 만든다. 잘 풀린 한 호흡은 컴보 보너스로 보상하는 것을 권장(향후).

### 4.4 매크로 루프 (60~90초 / 한 웨이브)
한 웨이브 = 3~4호흡. 적 종류·동시 등장 수·카운트다운 속도가 점차 가팔라지며 **완→급→완→정점** 곡선. 페이즈 변화는 무전 잡음·BGM 비트 강화로 청각 신호.

### 4.5 매크로 이상 (메타 루프)
**미정**. 다음 라운드 결정 사항:
- 단순 웨이브 클리어 → 스테이지/스토리 진행
- Hades 모델: 죽으면 1웨이브부터, 영구 업그레이드 누적
- Slay the Spire 모델: 매 런마다 노드 맵 분기

## 7. 영감을 받은 작품과 차별점

| 게임 | 무엇을 취했나 | 무엇을 버리거나 변형했나 |
|------|---------------|--------------------------|
| 두더지 게임 | 구멍에서 솟아나는 적·짧은 노출 윈도우 | 즉시 처치 → 카운트다운 압박으로 변형 |
| Duck Hunt / Time Crisis | 돌출-노출-회피 사이클 | 강제 카메라 이동(레일) 제거 |

| Hitman: Sniper | 한 자리에서 모든 타겟 처리 | 탑다운 → 사이드뷰로 |
| Sniper Elite | X-Ray 킬 캠의 임팩트 | 풍속·거리 시뮬레이션은 제거 |
| Superhot | 스코프 진입 시 시간 슬로우 | 시간 정지 → 0.3배속(부분 슬로우) |
| Receiver | 재장전을 게임성의 핵으로 | 7단계 디테일 → R 키 1+우클릭 1로 압축 |
| Pistol Whip | 음악 비트에 맞춘 적 등장 | 음악 → 적 무전 잡음 같은 청각적 큐로 변형 |

## 8. 차별화 지점 (이 게임만의 빈자리)
1. **사이드뷰 ↔ 스코프 토글**: Hitman: Sniper(탑다운)와 Sniper Elite(FPS) 사이의 빈 공간.
2. **두더지 그리드 + 한 발 무게감**: 라이트건의 즉발성과 정밀 저격의 한 발씩이 한 화면에 충돌.
3. **재장전이 게임성의 핵**: 대부분의 슈팅에서 재장전은 *성가신 시간*. 우리에겐 *결단의 지점*.
4. **밀리터리 톤 + 두더지 리듬감**: 보통 밀리터리 스나이퍼는 느린 잠입. 우리는 빠른 반응. 두 정서를 충돌시킴.
