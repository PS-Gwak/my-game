경매 규칙

  • 플레이어 1명 + CPU 10명이 경매를 진행합니다.
  • 경매 1회 = 그림 A→B→C→D→E 5라운드 경매 + 판매 세션.
  • 경매 시작 시 5라운드 경매 종류를 미리 공개합니다.
  • 예상가는 화면에 공개됩니다. 호가 판단 참고하세요.
  • 본인 재입찰 불가 — 누구든 연속으로 두 번 부르지 않습니다.
  • 10배속 보기 누르면 남은 시간이 ⏩ ×10 가속. 도중 다시 입찰하면 1배속 복귀.
  • 자유경매·1회 제한에서 마우스 휠 (위↑) / ↑↓ 방향키로 호가 단계 조절. Enter/Space로 입찰.
  • 자유경매는 사회자가 임의로 5~15초 간격으로 호가를 외칩니다. 침묵이 cooldown을 넘기면 종료.
  • 모든 화면에서 아무 키 / 아무 클릭으로 다음 단계 진행.
  • 판매 세션 종료 시 재산 < 0 이면 게임 오버. 시작 자금 $3,000.
  • CPU 10명도 각자 시작 자금 보유. 잔고 부족하면 파산💸 — 입찰 안 함. 자산은 $200~$5000 광분포.
