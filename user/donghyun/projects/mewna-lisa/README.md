## 시연 가이드

### 본 게임 (demo/)
1. 위 본 게임 링크 클릭
2. 작업실에서 그림 모작 그리기 → 자금 모음
3. 해금 단계 따라 점묘·유화·그라타주·박물관 엔딩 진행
4. 경매장 들어가면 5라운드 경매 진행

### 경매장 단독 시연 (auction-demo/)
1. 위 경매 단독 링크 클릭
2. 시작 자금 슬라이더로 자금 결정 ($100 ~ $50,000)
3. 경매 종류 드롭다운에서 1개 선택 (자유경매·네덜란드식·촛불 2등가·1회 제한·비밀입찰 + "5종 섞기")
4. 경매 시작 버튼 → 5라운드 자동 진행 → 결과 화면
5. 경매 도중 D 키를 누르면 우측에 자체 검증 패널 (무한 자금 / 즉시 종료 / CPU 성격 표시 토글)

## 구조 — D안 (본 게임 1개 + 시스템별 단독 데모 N개)
복합 시스템 게임 특성상 5판 비교 콘셉트는 부적합. 본 게임 전체 흐름 1개 + 시스템별 단독 데모를 따로 호스팅하는 방식으로 운영. 향후 작업실 단독·상점 단독 등 추가될 예정.
