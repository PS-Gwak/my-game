# 뮤더너츠 v9 — 30분 시연 리허설 시나리오

> 작성일: 2026-05-17  
> 대상: 뮤더너츠 v9 합숙 데모 시연자  
> 목적: 시연 도중 막히는 부분 없이 13단계를 순서대로 진행하기 위한 체크리스트

---

## 준비사항 (시연 전)

- 브라우저 주소창에 `index.html` 경로를 열어 게임 시작 화면 확인
- localStorage가 비어 있는지 확인 (개발자 도구 → Application → Local Storage → 모두 삭제)
- 화면 해상도: 1280×800 이상 권장

---

## 13단계 시연 시나리오

### 1단계 — 시작 메뉴 진입

**진행 방법:**  
게임을 열면 「뮤더너츠 v9」 시작 화면이 나타납니다.  
「이어하기」(저장 없으면 비활성) · 「새로 시작」 · 「자체 검증 모드」 3개 버튼 확인.

**검증 포인트:**
- 「이어하기」는 처음엔 흐릿하게 비활성 상태 (저장 데이터 없음)
- 「자체 검증 모드」 버튼 보임
- `Ctrl+Shift+D` 누르면 우측에서 패널이 밀려 나오는지 확인

---

### 2단계 — 새로 시작

**진행 방법:**  
「새로 시작」 버튼 클릭 → 확인 팝업 → 확인 → 작업실 화면으로 이동.

**검증 포인트:**
- 상단 HUD에 💰 $100 · 🖼 보유 0장 · 붓 1단계 · 수채화 0/4 표시
- 작업실 왼쪽에 「수채화」만 선택 가능, 나머지는 🔒 잠김

---

### 3단계 — 수채화 4장 모작

**진행 방법:**  
작업실 왼쪽 「수채화」 클릭 → 가운데에 원본 그림 5장 중 1장 선택 → 붓질 화면에서 마우스 드래그로 그리기 → 완성 후 「판매」 또는 「보관」 선택.  
이것을 4번 반복해서 수채화 4장 만들기.

**검증 포인트:**
- 붓질 화면에서 마우스를 드래그하면 색이 칠해지는지 확인
- 상단에 참고 그림(원본) 1장 고정 표시 확인
- 완성 후 등급·원본가·받을 금액 표시 → 판매 버튼
- 4장 완성 시 화면 가운데 「경매장이 열렸어요!」 알림 확인

---

### 4단계 — 경매장 진입 (1라운드)

**진행 방법:**  
작업실 왼쪽 하단 「경매장」 버튼 클릭 → 경매 화면 진입.

**검증 포인트:**
- v6 경매 화면 로드 확인 (자금 부족 가드 제거됨 — 자유 입장)
- 예상가가 화면에 공개 표시되는지 확인 (v7 룰)
- 호가 단위가 그림 가격의 10% 근사(5단위 반올림)로 동적 설정되는지 확인
  - 예시: 현재가 $200 → 호가 $10 / 현재가 $500 → 호가 $50 / 현재가 $1,000 → 호가 $100

> 빠른 자금 보충: `Ctrl+Shift+D` → ① 자원 탭 → 자금 슬라이더로 $1M 설정

---

### 5단계 — 1라운드 낙찰

**진행 방법:**  
경매에 참가해 1라운드 경매에서 낙찰 받기.  
「10배속 보기」 버튼으로 포기 없이 경과 확인 가능.

**검증 포인트:**
- 낙찰 후 자금에서 낙찰가 차감 확인
- 경매 라운드가 1라운드인지 확인 (수채화 4개 직후 상태)

---

### 6단계 — 보유 그림 3개 달성 → 점묘화 등장

**진행 방법:**  
작업실에서 수채화 모작을 「보관」으로 추가해 보유 그림 3개 채우기.

**검증 포인트:**
- 보유 3장 달성 시 「점묘화 도구 등장! 경매도 3라운드로 확장됐어요」 알림
- 작업실 왼쪽 「점묘화」 버튼이 활성화(자물쇠 해제)
- 경매 라운드가 3라운드로 변경됨

---

### 7단계 — 점묘 도구 사용 + 경매 3라운드

**진행 방법:**  
점묘화 원본 선택 → 붓질 → 완성 → 경매 3라운드 참가.

**검증 포인트:**
- 점묘화 물감 레벨이 채도에 영향 주는지 확인
- 경매 라운드가 3라운드로 진행되는지 확인

---

### 8단계 — 보유 그림 5개 달성 → 유화 등장

**진행 방법:**  
보유 그림을 5장으로 늘리기 (모작 보관 반복).

**검증 포인트:**
- 보유 5장 달성 시 「유화 도구 등장! 경매도 5라운드로 확장됐어요」 알림
- 작업실에 「유화」 버튼 활성화
- 경매 라운드 5라운드 확장 확인

---

### 9단계 — 유화 + 경매 5라운드

**진행 방법:**  
유화 원본 선택 → 붓질 → 완성 → 경매 5라운드 참가.

**검증 포인트:**
- 경매 화면에서 5라운드가 진행되는지 확인
- 5라운드 동안 CPU 입찰 패턴 확인

---

### 10단계 — 보유 그림 7개 달성 → 그라타주 등장

**진행 방법:**  
보유 그림을 7장으로 늘리기.

**검증 포인트:**
- 보유 7장 달성 시 「그라타주 도구 등장!」 알림
- 작업실에 「그라타주」 버튼 활성화

---

### 11단계 — 그라타주 모작

**진행 방법:**  
그라타주 원본 선택 → 붓질 → 완성.

**검증 포인트:**
- 그라타주 물감 레벨·채도 반영 확인
- 완성 후 등급 확인

---

### 12단계 — 자체 출품

**진행 방법:**  
금별1(7등급) 이상 모작 보유 시 「자체 출품」 해금.  
보유 그림 화면 → 해당 모작 선택 → 「자체 출품」 버튼 클릭 → 시작가·예상가 입력 → 경매 시작.

**검증 포인트:**
- 자체 출품 화면에서 시작가·예상가 입력 가능 여부 확인
- 경매 진행 후 본인 낙찰 시 차감액 $0 확인 (자기 작품 회수 공짜)

> 자체 출품 빠른 진입: `Ctrl+Shift+D` → ② 단계 탭 → 「자체 출품 해금」 체크 → 「모조품 추가」로 7등급 그림 추가

---

### 13단계 — 박물관 엔딩

**진행 방법:**  
그라타주 4등급 이상 보유 + 자금 $1,000,000 달성 시 「박물관 엔딩 도전 가능!」 알림.  
작업실 「박물관 엔딩」 버튼 → 엔딩 화면 확인.

**검증 포인트:**
- 박물관 엔딩 화면 정상 로드 확인
- 「새로 시작」 / 「계속 즐기기」 버튼 확인

> 빠른 엔딩 테스트: `Ctrl+Shift+D` → ② 단계 탭 → 「전체 해금」 → ① 자원 탭 → 자금 슬라이더로 $1,000,000 설정 → ① 자원 탭 → 모조품 추가 (그라타주 4등급) → 작업실로 이동 → 박물관 버튼 클릭

## 자체 검증 모드 빠른 사용법

| 목적 | 방법 |
|---|---|
| 패널 열기/닫기 | `Ctrl+Shift+D` |
| 자금 $1,000,000으로 맞추기 | ① 자원 탭 → 자금 슬라이더로 $1M 설정 |
| 특정 단계로 점프 | ② 단계 탭 → 해당 해금 체크박스 ON |
| 경매 강제 낙찰 | ③ 경매 탭 → 「다음 경매: 강제 본인 낙찰」 ON |
| 자금 부족 가드 무력화 | ① 자원 탭 → 「경매 가드 우회」 ON |
| 현재 상태 확인 | ④ 덤프 탭 → 「화면에 보기」 |
| 세이브 백업 | ④ 덤프 탭 → 「세이브 즉시 백업」 |
